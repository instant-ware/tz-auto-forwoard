🌟 About TZ AUTO FORWARD

TZ AUTO FORWARD is a Python-powered Telegram automation project developed by INSTANTWARE under the TZSMX branding.

This project is designed to make Telegram media forwarding easier, faster, and more convenient. It allows users to forward previously existing media files from a source Telegram channel to a destination channel and automatically monitor new incoming media messages.

Powered by the Telethon library, TZ AUTO FORWARD provides a simple terminal-based interface with colorful output, API credential configuration, batch processing, and automatic forwarding functionality.

Whether you want to organize your authorized Telegram channels, transfer media between channels, or automate repetitive forwarding tasks, TZ AUTO FORWARD provides a straightforward solution.

💎 Why TZ AUTO FORWARD?

- ⚡ Automatic forwarding of new media messages.
- 📦 Batch forwarding of previously existing files.
- 📂 Supports multiple media formats.
- 🔐 Secure Telegram API-based login.
- 🎨 Stylish and colorful terminal interface.
- 🛠️ Simple setup and configuration.
- 🐍 Lightweight Python-based project.
- 📱 Compatible with Termux and Linux.

Our Goal: To make Telegram file forwarding simple, convenient, and accessible.

🛠️ Installation Guide

📱 Termux (Android)

Step 1 — Update Termux

pkg update && pkg upgrade -y

Step 2 — Install Python and Git

pkg install python git -y

Step 3 — Clone Repository

git clone https://github.com/instant-ware/tz-auto-forwoard.git

Step 4 — Open Project Folder

cd tz-auto-forwoard

Step 5 — Install Required Packages

pip install telethon python-dotenv

Step 6 — Run TZ AUTO FORWARD

python tz-auto-forwoard.py

---

🐧 Linux (Ubuntu / Debian)

Step 1 — Update System

sudo apt update && sudo apt upgrade -y

Step 2 — Install Python and Git

sudo apt install python3 python3-pip git -y

Step 3 — Clone Repository

git clone https://github.com/instant-ware/tz-auto-forwoard.git

Step 4 — Enter Project Directory
